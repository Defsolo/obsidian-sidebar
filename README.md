# Sidebar

Obsidian 左侧导航插件。基于 [blank247d / sectioned-sidebar](https://github.com/blank247d/sectioned-sidebar) 1.1.7 的个人改版，界面固定中文。

分区由真实的文件夹和笔记支撑：可以手排固定项，也可以让某个分区实时跟随库根目录。

## 与原版的差别

所有本地改动都以 `LOCAL-PATCH n` 注释标在 `main.js` / `styles.css` 里（编号 1–43），可以直接对照。

- **拖放**：拖到文件夹行 = 真把文件移进那个文件夹；拖到跟随库根的分区 = 移回库根；拖到固定分区 = 把这项加进该分区（不动磁盘）
- **跟随库根的分区**（系统分区）：`source: rootFiles | rootFolders` 的分区内容每次渲染直接问库根要，新建的根文件夹/根笔记自动出现，可逐项隐藏
- **顶部工具条**：新建分区、排序方式（名称/修改时间/创建时间 × 两方向）、自动显示当前文件夹、全部展开↔折叠
- **配色与字号**：分区标题与行的字色、字号可调，留空则跟随主题
- **设置页**：分区名双击就地改名、上移/下移、清空系统分区的排除名单
- **观感**：层级竖线与核心文件列表同一套 token、行高与原生目录页对齐、去掉行首图标槽、去掉功能区图标

## 安装（手动）

1. 下载或克隆本仓库
2. 放到 `<vault>/.obsidian/plugins/sectioned-sidebar/`（目录名必须是 `sectioned-sidebar`）
3. 重载 Obsidian，在「第三方插件」里启用 **Sidebar**

插件 id 保持 `sectioned-sidebar`，因此与官方版的配置可以互相通用。

## 配置

`data.json` 是运行时配置（分区、展开状态、排序、配色），已被 `.gitignore` 排除。`data.example.json` 是脱敏示例，可改名后参考结构。

## 已知限制

- 固定分区里的项一律平铺、按加入先后倒序排列；工具条里的排序设置只作用于文件夹展开后的子项和跟随库根的分区
- 移动端没有 hover 与拖放：行内按钮常显，但拖放不可用
- 插件升级会直接覆盖本仓库的改动，升级前先备份
